# Prompts Nanobanana Pro — Images Express

8 prompts pour les couvertures des micro-méditations de la catégorie "Une minute pour toi". Style cohérent avec les 27 images existantes (palette midnight blue / turquoise, illustration minimaliste).

---

## Comment utiliser

1. Copie le prompt complet (le bloc en code) et colle-le dans Nanobanana Pro.
2. Exporte l'image en PNG carré (1024×1024).
3. Dépose-la dans `quieto-images-a-trier/` avec n'importe quel nom — je trierai.
