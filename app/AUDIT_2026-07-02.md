## 🔴 CRITIQUE (perte d'argent / rejet store)

### 1. Le bucket Firebase Storage est PUBLIC et listable
- **Où** : `lib/core/config/app_constants.dart:27` (audioBaseUrl → bucket `quieto-06.firebasestorage.app`)
- **Preuve** : requête HTTP réelle sans aucun token → HTTP 200 avec la liste complète des MP3. Tout l'audio premium est téléchargeable gratuitement. Le gating premium est 100 % côté client.
- **Fix** : règles Firebase Storage exigeant l'authentification + servir l'audio premium via URLs signées ou Cloud Function qui vérifie l'entitlement RevenueCat côté serveur.

### 2. Prix du paywall codés en dur en euros
- **Où** : `lib/features/paywall/presentation/paywall_page.dart:216-228`
- **Preuve** : « 4,99 € », « 11,90 € », « facturé 59,90 € par an », « Économise 58 % » en constantes. Les lignes RevenueCat (`sp.priceString`…) sont commentées. Prix affiché ≠ prix facturé pour tout compte hors storefront France → **motif de rejet Apple 3.1.2**.
- **Fix** : réactiver les lignes commentées (priceString / pricePerMonthString + savePct calculé).
- Note : c'était un choix volontaire (commentaire l.213) pour éviter le « $ » du compte sandbox US. Rappel : les vrais clients FR voient déjà € automatiquement via RevenueCat.
