# Prompts Nanobanana Pro — Images de session Quieto

27 prompts prêts à copier-coller pour générer les images de couverture des leçons.

---

## Comment utiliser

1. **Copie** le prompt complet de la session souhaitée (le bloc en code).
2. **Colle-le** dans Nanobanana Pro et lance la génération.
3. **Exporte** l'image en PNG carré (1024×1024 ou 1080×1080 minimum).
4. **Renomme-la** exactement comme indiqué (ex. `decouverte_1.png`).
5. **Dépose-la** dans le dossier indiqué (ex. `assets/images/sessions/decouverte/`) — elle remplacera le fichier vide.
6. **Vérifie** dans l'app : ouvre la leçon → l'image apparaît dans le player.

> Si l'image ne se charge pas (mauvais format), le placeholder note de musique s'affichera automatiquement en fallback.
